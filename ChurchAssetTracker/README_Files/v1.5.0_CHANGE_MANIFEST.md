# v1.5.0 – Platform Administration Update

## New
- Administration → System Settings
  - Organization name / short name
  - Portal name / subtitle
  - Website, email, phone, timezone
  - Organization logo upload
  - SMTP settings stored in database
  - Encrypted SMTP password
  - Send Test Email
  - Documentation Library path
  - Worship Library path
  - Path validation
  - Module Manager
- Administration → Setup Wizard / deployment checklist
- Administration → Dashboard Builder
  - Default, Church, School, IT and Admin profiles
  - Widget enable/disable
  - Drag/drop ordering
- Worship Song Library
  - Directory-backed search
  - View / Print
  - Download
- Collapsible sidebar groups with remembered state
- Sunday Ready IT / Sunday Ready Platform branding and copyright

## Changed
- Email service now reads runtime database-backed SMTP configuration.
- Documentation Library now reads its root path from runtime settings.
- Sidebar/module visibility honors Module Manager settings.
- Disabled optional modules are blocked server-side through a global module filter.
- Dashboard widget visibility/order can be customized by role profile.
- Login, layout and About page use configurable organization branding.
- Password invitation/reset and email-test messages use the configured portal name.
- Version bumped to 1.5.0 – Platform Administration Update.

## Database
- Adds dbo.SystemSettings only.
- Existing business tables are not modified.
- SQL migration: SQL/014_PlatformAdministration_v1_5_0.sql
- Runtime safe-create/seed is also included.

## Important
- Preserve App_Data/DataProtectionKeys during deployment and backup. Stored SMTP secrets depend on these keys.
- Existing appsettings EmailSettings and DocumentLibrary values are imported as initial defaults the first time database-backed settings initialize.
- ConnectionStrings remain in appsettings.json as bootstrap-critical configuration.
